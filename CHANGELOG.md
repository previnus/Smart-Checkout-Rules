# Changelog

## 2.0.0

- Add nested AND/OR conditions, deterministic priorities, rule duplication, bulk status changes, and module settings.
- Enforce payment, field, order-limit, and package policies in the Classic Checkout and Store API flows.
- Add a checkout simulator, schema-validated JSON import/export, purchase order reference, and optional diagnostics.
- Introduce revision-checked writes and preserve the 1.0 configuration for rollback.
- Raise requirements to PHP 8.3, WordPress 6.8, and WooCommerce 10.5.

## 1.0.0

- Initial Classic Checkout prototype for payment, shipping, minimum order subtotals and required fields.
